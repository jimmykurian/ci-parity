# P003 internal-task

CI calls a task that the task runner marks as internal, private or hidden.

**Severity:** error.

## Example

```yaml
# Taskfile.yml
version: "3"
tasks:
  deploy:
    cmds:
      - task: deploy:prod
  deploy:prod:
    internal: true
    cmds:
      - ./scripts/deploy.sh prod
```

```yaml
# .github/workflows/release.yml
jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - name: Deploy
        run: task deploy:prod
```

```text
.github/workflows/release.yml
  7:19   P003 internal-task 'deploy:prod' is marked internal: true and should not be invoked from CI
```

With just the message says `is private`, and with mise `is hidden`.

| Runner | Internal when |
| --- | --- |
| Taskfile | `internal: true` on the task, or on its include |
| just | `[private]`, or the name starts with `_` |
| mise | `hide = true`, or a `#MISE hide=true` line in a file task |
| make | never |

## Why it matters

Task refuses to run an internal task from the command line, so the step fails. With just
and mise, a private or hidden task is a helper the author didn't mean as an entry point.

## How to fix it

Call the public task that uses it (`task deploy` above), or make the task public if CI
should call it directly.
