import { CardGrid, LinkCard } from '@astrojs/starlight/components';

Add it to a workflow, after checkout:

```yaml
- uses: jimmykurian/ci-parity@v0
```

It reads Taskfile, make, just and mise tasks without running them, flags steps that call
`pnpm test`, `go build` and other tools directly, and suggests the task that already does
the same thing.
